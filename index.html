Project Case Study #2

Data Storytelling & Statistical Validation – Landing Page A/B Testing

Synthesizing analytical insights into a clear business narrative and validating landing page conversion performance using statistical hypothesis testing.

A/B Testing Hypothesis Validation Workflow

Data Storytelling, Conversion Rate Profiling, Two-Sample Z-Test & Decision Framing

View Full Repository on GitHub
1. Dataset Analyzed ab_data.csv containing 290,585 session logs (user_id, timestamp, group, landing_page, converted). Cleaned duplicates and verified group balance.
2. Hypotheses Formulated H₀ (Null): $p_{\text{new}} \le p_{\text{old}}$ (New page does not increase conversion)
H₁ (Alternative): $p_{\text{new}} > p_{\text{old}}$ (New page increases conversion)
3. Toolkit & Statistical Test Two-Sample Z-Test Python (SciPy.stats) Pandas / NumPy Seaborn / Matplotlib
4. Test Results & Decision Control: 12.02% vs Treatment: 11.88%. Calculated Z-Statistic $\approx 1.310$, P-Value $\approx 0.1897$ ($> 0.05$). Failed to reject Null Hypothesis ($H_0$). Recommended continuing with current page to avoid unnecessary deployment costs.

The observed conversion difference (-0.14%) has a p-value of 0.1897 (> α 0.05). We fail to reject the null hypothesis ($H_0$). The new landing page does NOT produce a statistically significant uplift.
